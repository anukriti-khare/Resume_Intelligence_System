Resume Intelligence System

Resume Intelligence System is an AI-powered application for analyzing and retrieving resumes. It uses a CNN-based deep learning model to classify resumes into different categories and combines FAISS semantic search with Retrieval-Augmented Generation (RAG) and a Groq LLM to answer questions, compare candidates, and identify relevant skills and experience from retrieved resumes. The retrieval system was evaluated using Precision@5 and achieved a mean score of 0.95. The application is built using Python, TensorFlow/Keras, Streamlit, FAISS, Hugging Face embeddings, LangChain, Groq, PyMuPDF, spaCy, and Scikit-learn.

Live App: https://resume-intelligent-system.streamlit.app/
